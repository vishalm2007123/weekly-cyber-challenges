# 🧩 Weekly Cyber Challenges

A weekly mini-CTF series designed to practice cybersecurity through small, practical challenges.

Every week, a new challenge is released covering topics such as:

* 🔐 Cryptography
* 🌐 Web Security
* 🔎 OSINT
* 📡 Network Forensics
* 🐧 Linux
* 🦠 Malware Analysis
* ☁️ Cloud Security
* 🧩 CTF Techniques

## 🎯 Goal

Learn cybersecurity by solving one practical challenge every week.

Each challenge is designed to focus on a specific security concept rather than simply solving a puzzle.
